# 🧮 Basic Java Maths Problems

---

## 1. Check Even or Odd
- Use `%` (modulus) operator to check remainder when divided by 2.  
- If `n % 2 == 0`, number is **even**, else **odd**.  
- Commonly used in control flow problems.  

---

## 2. Multiplication Table
- Use a **loop** (`for` or `while`) to generate multiples of a number.  
- Example: for 5, print `5 x 1 = 5` … `5 x 10 = 50`.  
- Good practice for learning iteration.  

---

## 3. Sum of Natural Numbers
- Natural numbers = `1, 2, 3, … n`.  
- Formula: **`n(n+1)/2`** (efficient).  
- Or calculate using a **loop**.  

---

## 4. Sum of Squares of Naturals
- Squares: `1² + 2² + 3² + … + n²`.  
- Formula: **`n(n+1)(2n+1)/6`**.  
- Useful for series and math problems.  

---

## 5. Swap Two Numbers
- Swap values of two variables.  
- Methods: using **temp variable**, **arithmetic operations**  
- Common interview question.  

---

## 6. Closest Number
- Find the nearest number divisible by m
- Use mod to get the quotient and quotient >=0 ? substract from num : add to num; 

---

## 7. Dice Problem
- Dice has 6 faces numbered `1–6`.  
- Opposite faces always sum to **7** (`1↔6, 2↔5, 3↔4`).  
- Problem usually asks: given one face, find opposite.  

---

## 8. Nth Term of Arithmetic Progression (AP)
- AP formula: **`a + (n-1)d`** where `a = first term`, `d = common difference`.  
- Direct formula avoids looping.  
- Used in math + coding test problems.
