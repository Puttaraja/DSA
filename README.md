# 🚀 Java Data Structures & Algorithms (DSA)

This repository contains implementations and practice of **Data Structures and Algorithms (DSA)** in **Java**.  
It covers both **linear** and **non-linear** data structures, along with standard DSA problems and operations.

---

## 📌 Topics Covered

### 🔹 Linear Data Structures
- Arrays
- Strings
- Linked List (Singly, Doubly, Circular)
- Stack (using Arrays / LinkedList)
- Queue (Simple, Circular, Priority Queue, Deque)

### 🔹 Non-Linear Data Structures
- Trees  
  - General Tree (Adjacency List Representation)
  - Binary Tree (Insertion, Traversals: Inorder, Preorder, Postorder, Level-order)
- Binary Search Tree (BST)
- Graphs (Adjacency List, BFS, DFS, Shortest Paths)

---

## ⚡ Features
- Implemented **basic operations** (insertion, deletion, traversal).
- **Iterative & Recursive** solutions where applicable.
- **Helper utilities** for debugging and visualization.

---

## 📊 Time Complexities (Overview)

| Data Structure  | Insertion | Deletion | Search | Traversal |
|-----------------|-----------|----------|--------|-----------|
| Array           | O(1)/O(n) | O(n)     | O(n)   | O(n)      |
| Linked List     | O(1)      | O(1)/O(n)| O(n)   | O(n)      |
| Stack / Queue   | O(1)      | O(1)     | O(n)   | O(n)      |
| Tree (BT)       | O(log n)  | O(log n) | O(log n)| O(n)    |
| Graph (Adj. List)| O(V+E)   | O(V+E)   | O(V+E) | O(V+E)    |
